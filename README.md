# 巴别图书馆 · The Library of Babel

> 「图书馆是一个球体，它精确的中心是任何一个六边形，它的圆周是远不可及的。」——博尔赫斯

一座包含所有可能文本的无限图书馆。你输入的任何一句话——说过的话、未说出的话、明天才会写下的话——都早已写在某本书的某一页上。网站不存储任何文本：每一页的内容由其地址唯一决定，检索不是寻找，而是定位。

## 特性

- **检索即定位**：输入任意文字（中/英/emoji/生僻字均可），返回 10 处真实书页坐标，原句高亮
- **短链接**：检索结果与随机漫游使用「配方」短链接（约 50–100 字符），打开时精确重建整页
- **全 Unicode 字符集**：154,826 个可打印字符（Unicode 16.0 快照，地址永久不漂移）
- **乱码填充语言池**：汉字 / 拉丁 / 假名 / 韩文 / 西里尔 / 阿拉伯文 / 数字标点 / emoji，或限定为任意一段文字的字符
- **长文本**：上传 .txt/.md（UTF-8/GBK）或粘贴超长文本，自动分段逐页定位
- **馆藏名著**：《道德经》《孙子兵法》《论语·学而第一》《唐诗十二首》《莎士比亚十四行诗》，每章一页
- **寻找我的辩护书**：凡可被写下的辩护，必然写在某一页上——包括为你的那一份
- 翻页导航、所属书籍、反向定位、只看原句、分享文案、暗色模式、打印藏书票、PWA 离线访问

## 原理（无数据库，纯前端）

- 一页 4000 个字符 ⇔ 一个 154,826 进制的 4000 位大整数（页编号），互为双射；再经两层互素乘法取模换算（内容打乱 + 地址打乱），浏览器原生 `BigInt` 计算，约毫秒级
- **检索**：把查询放在随机位置、用随机字符填满整页，再编码成地址——每个结果都是馆中真实、永久有效的一页
- **短链接**：乱码填充由种子确定性随机流（splitmix64）生成；链接携带「种子 + 位置 + 语言池掩码 + 限定文本 + 检索词」即可完整重建整页。配方算法与字符集均为永久契约，不可变更

## 开发

```bash
npm install
npm run dev        # 开发预览（默认 5173 端口）
npm test           # 单元测试（vitest，49 项）
npm run build      # 产出 dist/，可部署到任意静态托管
npm run gen:alphabet   # 重新生成字符集区间表（会使所有地址失效，慎用）
```

端到端回归（需本机装有 Edge，且 dev server 在 5173 端口运行）：

```bash
npx vite-node scripts/e2e-click.mjs
```

## 结构

```
src/core/         纯函数核心：字符集、编解码、地址分层、检索/配方、语言池、文案
src/classics/     馆藏名著数据（由 scripts/build-classics.mjs 生成，公版文本）
src/pages/        Home / Page / Book / Classic / About
scripts/          字符集生成、名著抓取清洗、真实浏览器 e2e
tests/            vitest 单元测试
```
