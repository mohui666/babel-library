# 巴别图书馆 · The Library of Babel

> 「图书馆是一个球体，它精确的中心是任何一个六边形，它的圆周是远不可及的。」——博尔赫斯

一座包含所有可能文本的无限图书馆。你写下的任何一句话，都早已存在于某一页——网站不存储任何文本：每一页的内容由其地址唯一决定，检索不是寻找，是定位。

## 体验

写下一句话 → 坐标逐层揭示（馆 → 层 → 室 → 架 → 册 → 页）→ 翻开那一页 → 看到它早已在那里。

## 特性

- **检索即定位**：一次定位一页，坐标逐层揭示；「在图书馆的另一处寻找同一句话」
- **短链接**：检索/漫游/翻页/书籍页均为配方或相对短链接（约几十字符）；名著为语义短路由；文字页为 `/v1/t/` 文字链接——全部浏览路径无长链接
- **/v1 版本契约**：字符集、页长、常数、配方算法冻结，旧链接永久可解码（`src/core/codec.ts` 顶部）
- **全 Unicode 字符集**：154,826 个可打印字符（Unicode 16.0 快照）
- **阅读页**：默认聚焦原句、只显示上下文，完整书页折叠；翻页导航、所属书籍、暗色模式、打印藏书票
- **藏书票图卡**：三种装帧（宇宙收录证/未来墓志铭/原始藏书票），canvas 生成可下载 PNG，含二维码与坐标
- **一键分享**：优先系统分享面板（可带图），不支持时回退复制文案
- **馆员索引**：辩护书、今日之页（全馆同日一页）、馆员已经标记的几页（《道德经》《孙子兵法》《唐诗》等公版文本，连读 + 章际导航）
- **主题入口**：未来墓志铭 / 从未说出口的话 / 十年后的自己（按日轮换）；**合著接写**：链接携带前半句邀朋友续写
- **更多定位方式**：上传 .txt/.md（UTF-8/GBK）自动分段定位；页面书写体系（汉字/拉丁/假名等 8 池）；限定字符集
- 我的藏书夹（localStorage）、反向定位、真目录隐藏彩蛋、PWA 离线访问

## 原理（无数据库，纯前端）

- 一页 4000 个字符 ⇔ 一个 154,826 进制的 4000 位大整数（页编号），互为双射；再经两层互素乘法取模换算（内容打乱 + 地址打乱），浏览器原生 `BigInt` 计算，约毫秒级
- **检索**：把查询放在随机位置、用随机字符填满整页，再编码成地址——结果都是馆中真实、永久有效的一页
- **配方短链接**：乱码填充由种子确定性随机流（splitmix64）生成；链接携带「种子 + 位置 + 书写体系掩码 + 限定字符集 + 检索词」即可完整重建整页
- **文字页链接**：页面由用户文字 + 空白补齐唯一决定，链接只携带文字本身

## 开发

```bash
npm install
npm run dev        # 开发预览（默认 5173 端口）
npm test           # 单元测试（vitest，52 项）
npm run build      # 产出 dist/，可部署到任意静态托管
npm run gen:alphabet   # 重新生成字符集区间表（会使所有地址失效，慎用）
```

端到端回归（需本机装有 Edge，且 dev server 在 5173 端口运行）：

```bash
npx vite-node scripts/e2e-click.mjs   # 18 个真实浏览器场景
node scripts/make-og.mjs              # 重新生成 public/og.png
```

## 结构

```
src/core/         纯函数核心：字符集、编解码、地址分层、检索/配方、语言池、文案、图卡、今日页、藏书夹
src/classics/     馆员标记文本（由 scripts/build-classics.mjs 生成，公版）
src/pages/        Home / Page / Book / Classic / About
scripts/          字符集生成、名著抓取清洗、真实浏览器 e2e、OG 图生成
tests/            vitest 单元测试
```
